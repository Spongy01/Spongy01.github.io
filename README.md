# Portfolio

Static site for GitHub Pages. No build step: plain HTML, CSS, and a little JavaScript.

## Files

- `index.html` — home page
- `styles.css` — all styling, light and dark themes
- `script.js` — theme toggle and the scroll reveal
- `projects/*.html` — placeholder project pages
- `assets/pfp.jpeg` — portrait
